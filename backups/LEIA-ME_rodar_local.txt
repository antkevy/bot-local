COMO RODAR NO SEU PC (Windows), SE QUISER VOLTAR A RODAR LOCAL:
---------------------------------------------------------------
1) Extrair o .tar.gz numa pasta (7-Zip ou `tar -xzf` / Git Bash).
   Ex.: C:\bot-local
   Se a pasta já existir e tiver dados antigos, use uma pasta NOVA.

2) Instalar o uv (se ainda não tiver):
   https://docs.astral.sh/uv/
   ou: pip install uv

3) Dentro da pasta extraída, instalar dependências:
   > uv sync

4) Reinstalar o navegador do Playwright (não vem no backup):
   > uv run python -m ofertas instalar-navegador

5) Rodar o painel:
   > uv run python -m ofertas painel
   Depois abrir no navegador: http://127.0.0.1:8481
   (login: usuário/senha que estão no seu .env, chaves PAINEL_*)

6) Ligar o bot: no painel, botão "Ligar Bot" (funciona localmente,
   pois não há systemd no PC), ou num terminal:
   > uv run python -m ofertas run
